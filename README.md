# Railway Operations Analysis – Excel Dashboard

## Project Overview
This project analyzes railway train operations using Microsoft Excel. The dashboard provides insights into train arrival delays, punctuality, station-wise performance, and daily arrival trends.

The main objective is to understand train arrival performance and identify stations and days with higher average delays.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- Excel Formulas
- Conditional Formatting
- Data Visualization
- Excel Charts

## Dataset
The dataset contains train schedule and actual arrival and departure information, along with delay values and station details.

**Dataset Columns:**
- Train
- Date
- Station
- Scheduled Arrival
- Actual Arrival
- Arrival Delay
- Scheduled Departure
- Actual Departure
- Departure Delay

## Data Preparation
- Checked for missing values and duplicate records.
- Formatted date and time columns.
- Created Arrival Status and Departure Status columns.
- Categorized trains as Early, On Time, or Delayed.
- Created a Day Name column.
- Applied conditional formatting to highlight delays.

## Key Performance Indicators (KPIs)
1. Total Train Records
2. Average Arrival Delay
3. Average Departure Delay
4. Delayed Train Percentage

## Dashboard Charts
1. Train Arrival Status – Doughnut Chart
2. Top 10 Stations by Average Arrival Delay – Bar Chart
3. Average Arrival Delay by Day – Line Chart
4. Arrival Status by Day – Stacked Column Chart

## Key Insights
- Analyzed the distribution of early, on-time, and delayed train arrivals.
- Identified stations with higher average arrival delays.
- Compared average arrival delays across different days of the week.
- Examined daily arrival punctuality patterns.

## Important Data Limitation
The source dataset contains identical values in the Arrival Delay and Departure Delay columns. Therefore, these two fields should not be treated as independent measures when comparing arrival and departure performance.
